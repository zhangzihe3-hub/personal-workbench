# 个人工作台 · 使用说明

版本：1.0.0

## 1. 快速上手

1. 打开 Linux 服务器部署地址，或安装 Android App 并填写服务器的 HTTPS API 地址
2. 输入服务器账号密码；首次使用会展示新手引导
3. 在「任务」页顶部输入一句话即可创建任务；在「日程」页顶部输入一句话即可创建日程
4. 数据统一保存在服务器 MySQL 中，Web 和 Android 使用同一份数据

## 2. 全局快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + K` | 呼出全局搜索（跨任务/日程/笔记） |
| `Ctrl + N` | 快速新建任务 |
| `Ctrl + Shift + N` | 快速速记（保存为临时笔记） |
| `Ctrl + Z` | 撤销上一步操作（新增/修改/删除均支持） |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 重做 |
| `Esc` | 逐层关闭弹窗/侧滑面板/搜索/速记 |

> 说明：在输入框/编辑器中按 Ctrl+Z 走系统文本撤销，不影响应用级撤销。

## 3. 模块操作指南

### 3.1 工作台（首页）

- 今日概览：今日待办数、今日日程数、今日完成数、延期任务数，点击卡片跳转对应模块
- 待办清单：按置顶、四象限和截止时间排序的前 5 项待办，勾选直接完成（可撤销）
- 今日日程时间轴：按时间展示当日日程，过期置灰
- 最近笔记：最近更新的 3 篇，点击打开详情
- 今日专注：番茄钟今日/累计专注时长

### 3.2 任务

- **快速录入**：顶部输入框一句话创建，自动识别时间、重要/紧急、重复周期和标签
  - 示例：`明天18点前 重要紧急 完成需求文档 #工作` → 截止明天 18:00、重要紧急、标签 工作
  - 支持：今天/明天/后天、周几/下周三、N天后、几点几分、重要、紧急、每天/每周/每月/每年、#标签
- **筛选**：左侧筛选栏支持状态/四象限/分类/标签/时间范围（今日/本周/本月/自定义）+ 关键词
- **排序**：默认按「置顶 → 四象限 → 截止时间升序 → 创建时间降序」；可切换手动拖拽排序
- **视图**：支持四种视图切换
  - 列表视图：默认视图，完整信息展示，可拖拽排序
  - 分组视图：按分类、四象限、状态分组展示
  - 看板视图：按状态分列（待开始/进行中/已延期/已完成/已取消），**拖拽任务卡片即可切换状态**（可撤销），适合流水线式推进任务
  - 甘特图视图：以时间轴展示任务进度（横条从创建时间到截止时间），支持 7/14/30/90 天范围切换，含今天参考线，颜色区分状态（灰=待开始、蓝=进行中、红=已延期、绿=已完成），无截止时间的任务不显示并在顶部提示
- **批量操作**：点「多选」进入多选模式，批量完成/删除/改分类/改四象限/加标签
- **右键菜单**：在任务项上右键可快捷修改四象限、状态、分类和置顶状态
- **子任务**：详情面板中管理子任务，全部完成后提示是否完成主任务
- **状态流转**：待开始 ↔ 进行中 → 已完成/已取消；超过截止时间未完成自动标记「已延期」（每小时校验）

### 3.3 日程

- **快速录入**：顶部输入框一句话创建，自动识别起止时间与地点
  - 示例：`下周三下午2点到4点 项目评审会 会议室A` → 下周三 14:00-16:00，地点 会议室A
- **三种视图**：日/周/月视图，顶部切换；点击「今天」回到当前
- **时间冲突检测**：新增/修改日程时自动检测重叠，冲突时段高亮提示（允许保存）
- **拖拽操作**：月视图拖拽色条改日期；周/日视图拖拽移动、拖底部手柄拉伸时长
- **重复日程**：支持每日/每周/每月/每年重复，可设置结束日期；编辑/删除时可选「仅本次 / 本次及未来 / 全部」
- **提醒**：到达提醒时间弹出页面提醒 + 桌面通知（需授权），含关联任务入口

### 3.4 笔记

- **Markdown 编辑**：即打即得（IR 模式），工具栏含标题/加粗/列表/表格/代码/图片等，图片本地 base64 存储
- **自动保存**：编辑过程中每 30 秒自动保存 + 失焦保存，标题自动取正文前 15 字
- **文件夹**：一级文件夹管理，新建/重命名/删除（删除后笔记移入「临时笔记」）
- **标签**：全局标签，按标签筛选
- **双链关联**：正文输入 `[[任务标题]]` 或 `[[日程标题]]` 自动建立双向关联，点击可跳转；任务/日程详情中反向展示关联笔记
- **检索**：全文检索（标题+正文）命中高亮；可按文件夹/标签/创建时间筛选
- **导出**：单篇导出 Markdown；批量导出全部为 ZIP 压缩包

### 3.5 统计

- 周期切换：本周 / 本月 / 自定义日期范围
- 任务维度：总数、完成数、完成率、延期率、取消率，四象限分布、分类占比（环形图）
- 日程维度：总数、总时长、平均时长、分类占比
- 时间分布：每日任务完成数趋势、每日日程时长趋势
- **周期复盘报告**：周报/月报自动生成，含数据概览（同比环比）、亮点总结、问题分析（延期关键词）、行动建议，可导出 Markdown

### 3.6 工具箱

- **番茄钟**：工作/休息倒计时（默认 25+5 分钟，可在设置中调整），可关联任务，完成自动记录专注时长；专注模式全屏倒计时
- **日期计算器**：两日期间隔（自然日 + 工作日）；指定日期 + N 天/周/月 推算
- **常用收藏夹**：网址 / 本地文件路径 / 常用话术三类，网址一键打开，文件与话术一键复制

### 3.7 目标与习惯

- **目标**：周/月/季度/年度目标，拆解关键结果（KR），KR 可关联任务；按 KR 完成比例自动计算目标进度
- **习惯打卡**：每日或每周 X 天频率、提醒时间；今日打卡、近 30 天补打卡（点击日历格子）；连续打卡天数与打卡率自动统计

### 3.8 系统设置

- 基础设置：工作时间段、默认提醒时长、番茄钟时长、主题（浅色/深色/跟随系统）、主色调
- 分类与标签：任务/日程分类增删；全局标签新增/删除/合并
- 数据管理：**导出 JSON 备份**（可选密码加密）、**导入 JSON**（覆盖式，导入前二次确认）、一键清空（双重确认）
- 安全设置：应用解锁密码（SHA-256 本地存储）+ 自动锁定时长（5/10/30 分钟/从不）；顶栏可手动锁定
- 关于：版本信息、重新播放新手引导

## 4. 数据安全建议

- 首次使用后建议立即导出一次 JSON 备份（设置 → 数据管理）
- 如需隐私保护，可设置解锁密码并开启自动锁定
- 业务数据保存在服务器 MySQL；请同时备份 MySQL 数据卷与应用导出的 JSON
- Android 应只连接可信 HTTPS 地址，不要在公共网络使用明文 HTTP
