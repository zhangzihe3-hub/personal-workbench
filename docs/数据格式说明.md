# 个人工作台 · 数据格式说明

版本：1.0.0

## 1. 存储架构

- 底层使用服务器 **MySQL 8.4**；所有业务对象存放在 `pwb_records` 的 JSON 列中，当前数据版本号 `3`
- 日期时间统一存储为 **ISO 8601 字符串**（含本地时区偏移，如 `2026-08-05T18:00:00+08:00`）
- 全量数据可通过「设置 → 数据管理 → 导出 JSON」导出为单个 JSON 文件；同页支持导入（覆盖式）

## 2. 导出文件结构

```json
{
  "app": "personal-workbench",
  "version": 3,
  "storage": "mysql",
  "exported_at": "2026-08-04T16:00:00.000Z",
  "tables": {
    "tasks": [],
    "schedules": [],
    "notes": [],
    "folders": [],
    "tags": [],
    "categories": [],
    "goals": [],
    "habits": [],
    "habit_logs": [],
    "favorites": [],
    "pomodoro_logs": [],
    "configs": [],
    "saved_views": []
  }
}
```

- `version`：数据版本号，用于向下兼容；升级时导入旧版本数据自动按字段缺失默认值兜底
- 勾选「密码加密」时，导出内容为 `PWB_ENCRYPTED_V1:<base64>` 形式（XOR 混淆级保护，防本地窥探，非强加密；导入时需输入导出时设置的密码）

## 3. 数据表结构

### 3.1 tasks 任务表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| task_id | string | 主键，UUID |
| title | string | 标题，≤200 字 |
| description | string | 描述，支持 Markdown |
| important / urgent | boolean | 重要、紧急两个维度，组合为四象限 |
| status | enum | todo/doing/done/canceled/delayed |
| start_time | string\|null | 可选开始时间 ISO |
| deadline | string\|null | 截止时间 ISO |
| category | string | 分类，默认「待分类」 |
| tags | string[] | 标签 |
| subtasks | object[] | 子任务 `[{subtask_id, title, status: 'todo'\|'done'}]` |
| related_schedule_ids | string[] | 关联日程 ID |
| related_note_ids | string[] | 关联笔记 ID |
| repeat_type | enum | none/daily/weekly/monthly/yearly/exception |
| repeat_end | string\|null | 重复结束日期 ISO |
| canceled_dates / completed_dates | string[] | 重复任务跳过/完成的实例日期 |
| exception_of / exception_date | string\|null | 例外实例的主任务与原始日期 |
| remind_minutes | number\|null | 提前提醒分钟数，null 跟随全局设置 |
| pinned | boolean | 是否置顶 |
| sort_order | number | 手动排序权重 |
| created_at / updated_at / completed_at | string\|null | 创建/更新/完成时间 |

### 3.2 schedules 日程表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| schedule_id | string | 主键，UUID |
| title | string | 标题，≤200 字 |
| start_time / end_time | string | 起止时间 ISO，end > start |
| location | string | 地点 |
| attendees | string[] | 参会人 |
| remind_minutes | number | 提前提醒分钟数，0 不提醒，默认 15 |
| repeat_type | enum | none/daily/weekly/monthly/yearly/exception |
| repeat_end | string\|null | 重复结束日期 ISO |
| exception_of | string\|null | 例外实例指向的主日程 ID（仅 repeat_type=exception） |
| exception_date | string\|null | 例外对应原始日期 YYYY-MM-DD |
| canceled_dates | string[] | 主日程上跳过的日期（仅本次删除） |
| category | string | 分类，默认「默认」 |
| remark | string | 备注，支持 Markdown |
| related_task_ids | string[] | 关联任务 ID |
| created_at / updated_at | string | 创建/更新时间 |

> 重复日程渲染机制：主记录存 `repeat_type`，展示时按区间展开为实例；「仅本次」修改生成 exception 实例（复用主日程时间），「仅本次」删除记录到 `canceled_dates`。

### 3.3 notes 笔记表

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| note_id | string | 主键，UUID |
| title | string | 标题，默认取正文前 15 字 |
| content | string | 正文，Markdown |
| folder | string | 所属文件夹，默认「临时笔记」（一级结构） |
| tags | string[] | 标签 |
| related_task_ids / related_schedule_ids | string[] | 双链关联（由 `[[标题]]` 自动维护） |
| word_count | number | 正文字数（自动计算） |
| created_at / updated_at | string | 创建/更新时间 |

### 3.4 元数据表

**folders**：`{name}`（主键），一级文件夹

**tags**：`{name, type}`，type 为 task/schedule/note/common（当前统一按全局标签使用）

**categories**：`{name, type}`，type 为 task/schedule；当前以 `name` 为主键，因此任务与日程分类名称全局唯一

**saved_views**：`{view_id, name, filters, created_at}`，保存任务页筛选条件形成智能清单

### 3.5 目标与习惯

**goals**：

```json
{
  "goal_id": "uuid",
  "title": "目标标题",
  "description": "描述",
  "period": "week|month|quarter|year",
  "metric": "衡量标准",
  "deadline": "ISO|null",
  "key_results": [{ "kr_id": "uuid", "title": "KR 标题", "done": false, "related_task_ids": [] }],
  "status": "active|done",
  "created_at": "ISO",
  "updated_at": "ISO"
}
```

**habits**：`{habit_id, title, frequency_type: 'daily'|'weekly', weekly_days: [1..7], remind_time: 'HH:mm', status: 'active'|'archived', created_at}`

**habit_logs**：`{log_id, habit_id, date: 'YYYY-MM-DD', checked_at}`（同一天重复打卡幂等）

### 3.6 工具箱

**favorites**：`{fav_id, type: 'url'|'file'|'text', title, content, created_at}`

**pomodoro_logs**：`{log_id, task_id|null, minutes, start_time}`

### 3.7 configs 配置表

KV 单条记录：`{key, value}`

- `app_settings`：全部应用设置（工作时间段、提醒时长、番茄钟时长、主题、主色、自动锁定、密码哈希 `passwordHash`（SHA-256）、新手引导完成标记 `onboarded`、侧边栏收起状态）

## 4. 兼容性规则

- 导入仅处理导出文件中存在的表；缺失字段由读取方默认值兜底，保证旧版本数据可导入
- 导入为**覆盖式**，会清空对应表后写入，操作前应用会二次确认
- 旧版 IndexedDB 导出的 JSON 可直接从设置页导入服务器；P0/P1/P2/P3 字段由现有兼容逻辑映射为四象限
- 服务端导入使用 MySQL 事务，各逻辑表按导出内容覆盖，数据版本继续向下兼容
